# Issue tracker: Local markdown

Issues and PRDs for this repo are tracked as markdown files under `.scratch/` in this repository.

## Conventions

- **Create an issue**: create a markdown file in a feature folder, e.g. `.scratch/<feature>/issue-<short-title>.md`.
- **Issue format**: include `Title`, `Context`, `Acceptance criteria`, `Status`, and `Notes` sections.
- **Update progress**: append timestamped notes in the `Notes` section and update the `Status` value.
- **Close an issue**: mark `Status: done` and keep the file for history.

Use plain markdown files as the source of truth. Do not call GitHub or GitLab issue APIs for this repo.

## When a skill says "publish to the issue tracker"

Write a markdown issue file under `.scratch/`.

## When a skill says "fetch the relevant ticket"

Open the corresponding markdown file under `.scratch/`.
